Four views. One question each.

Every view answers a different question about the same store, and the same numbered proof follows you between them.

what shape is the model?

Schema

One card per type with its relations, cross-type links as edges, plus a model-health check.
how does a relation compute?

Resolution

The rewrite tree Check walks — any of, all of, but not — lit up as the trace runs.
what is in the store?

Data

Tuples as edges into object#relation slots, derived access on demand.
who can do what?

Matrix

Subjects × objects, direct vs derived; click any cell for its proof.

It explains the no, too.

A denied check shows the branch that got furthest, the exact step it broke on, and the tuples that would flip the answer — each one verified by re-running the check.
